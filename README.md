# Grate Portfolio

A minimal, dark, Onyx-accented personal portfolio for Grate.

## Run locally

No build step is required.

Open `index.html` in a browser, or use any simple static server.

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Import the repository into Vercel.
4. For a static site, Vercel can deploy it directly.
5. No environment variables are required.

## Things to customize

- Replace the GitHub URL in `index.html`.
- Replace the Discord placeholder in `script.js`.
- Update the `Server` value when you're ready.
- Add/remove projects in the Projects section.
- Change the title/description in `<head>` if desired.

## Design

Dark background + Onyx surfaces, subtle borders, large typography, responsive layout, and lightweight scroll animations.

# Grate portfolio

Standalone Vite + React export. No workspace packages or backend required.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it locally with `npm run preview`.

## Deploy to Vercel

Deploy this folder as the Vercel project root. From its directory, run `vercel` and follow the prompts, or import the repository and set **Root Directory** to `artifacts/grate-portfolio/vercel-export`. The included `vercel.json` configures the Vite build and static output.

## Editing

Edit the copy and links in `src/App.tsx`; styles live in `src/index.css`. The Aster MC image is in `public/assets/aster-mc.jpg`.
